## 3. Technical Learnings
- **`tools/todo_archive.py` mangles a `**Owner runs:**` line.** It takes the bold text as the Done stub's title, which gives `**Owner runs:**`, and the first date in the line (the `since` date) as the close date. Fix the stub by hand after running it, as done here. This is worth telling `server`/`template` if the format spreads.
- **A ghost "queued" Actions run** can't be cancelled and blocks nothing once a new push triggers a fresh run. `gh run list --branch <b>` shows both.
- **Archiving order:** a late-merging older handoff must land in `archive/` if a newer one is already archived. Check this by running `tests/test_loaded_path.py` on the merged tree, not on the branch.
- **The auto-mode classifier** refused one long chained command: cancel run + branch + merge + mv + push. Split into steps after the owner engaged, it ran fine.
- **The handoff sync check** compares against the last commit under `session-summary/`, and #47's merge moved that point past #55. It printed nothing even though #55 changed `docs/BRIEF.md`. Owner Sync is tracked in TODO.md instead.
