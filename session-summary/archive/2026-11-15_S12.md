## 3. Technical Learnings
- **A pipe masks a failed gate.** A verification chain ending in `| tail -1` let a `check_doc_citations.py` ERROR through. Run gates with `set -o pipefail` before chaining `&& git commit`.
- **`check_doc_citations.py` also scans `data/raw/private/`** locally. A private file that cites a doc by line number (`SPEC_x.md:15-18`) fails the public repo's gate. Cite by section instead.
- **Run new public text through the corpus match** (exact strings and word n-grams from the private repo) before committing it. It caught one 4-gram in a TODO line this session.
- **Drive auth as built (unexercised):**
  - `src/inventory.build_service(config_dir, scopes, token_name)`, with config in `~/.config/drive-landscape/` (override with `DRIVE_LANDSCAPE_CONFIG`).
  - Inventory uses `drive.readonly` with `token.json`; `src/live.py` uses `drive.file` with `token-live.json`.
  - `run_local_server`, so the first consent needs a local browser (the laptop).
  - No config dir exists on this box and there is no cron.
- **Audit limits.** The corpus holds the one todo list only: no inventory or live data exists yet. The three titles scrubbed on 2026-10-05 are unrecoverable. Actions logs were not read.
