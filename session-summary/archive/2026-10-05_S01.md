## 3. Technical Learnings
- **The owner syncs Claude web by ticking repo paths in the claude.ai GitHub picker**, and it worked while the repo was private. A path appears only once it is on `master`.
- **Reminders PDF layout** (iOS 18.5 print): real text layer, no images; each reminder has an ~11×11 pt marker rect at x≈24 and title text at x≈43, 10.7 pt; wrapped title lines have no marker; a subtask's marker sits at x≈43 with text at x≈62; a 9.6 pt line under an item is its date; 8 pt lines are footers; the 19 pt line is the list name plus item count. **Every marker is drawn identically, so done / not-done cannot be recovered.**
- **PyMuPDF is AGPL** — tried for inspection, removed; `pdfplumber` (MIT) sees the same rects and fonts. `poppler` tools are not installed on the server.
- **fastembed timing** (measured by `edmonton-open-data-landscape` on this server, 4 ARM cores): 1,400 texts of ~60 characters in 7.8 s. Its earlier "4 minutes for 920" was long texts at the 512-token cut. Pass `cache_dir=~/.cache/fastembed` (the default is a temp dir); the cache is shared between projects. Vectors differ slightly across machines.
- **That project has not chosen a method**: embed 49% vs TF-IDF 47% top-5 same-category; labelling at 52 of 210. Its lessons are in `TODO.md` and `docs/SPEC_drive_landscape.md` §6.
- **The claude.ai Drive connector is too costly for bulk work**: one folder listing was ~50 KB of context. Use the Drive API from Python.
- **A read hook logs file paths** to `~/.claude/retrieval-log.jsonl` (outside both repos), hence neutral ids such as `todo-001` for private files.
- **Never print private text.** This session worked on the real list through counts and layout only; keep doing that, and keep real names out of tracked files, commit messages and PR text. The guard cannot recognise a typed name or todo text.
- **`docs/BRIEF.md` is generated**: re-run `.venv/bin/python scripts/make_brief.py --write` in any PR that touches `CLAUDE.md`, `TODO.md`, `docs/SCOPE.md`, `docs/DECISIONS.md`, `docs/DATA_ISSUES.md` or the requirements files, or `tests/test_brief.py` fails.
- **GitHub free plan:** branch protection is unavailable on private repos, so it only became possible once this repo went public.
- **Important files:** `docs/SPEC_phase1_distill.md`, `docs/SPEC_drive_landscape.md`, `data/DATA.md`, `TODO.md`, `docs/DECISIONS.md`, `src/inventory.py`, `src/reminders_pdf.py`, `scripts/check_no_private_data.py`, `.githooks/pre-commit`.
