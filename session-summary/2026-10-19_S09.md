## 4. Technical Learnings
- **Entry shape for keep:** `{"op": "keep", "item": N}`, not `"items"`. The `EDITS` table in `src/distill.py` (around line 386) gives every op's fields. My first test used `items` and got a 400.
- **Preview uses draft mode on purpose.** Without it the 56 unconfirmed groups would be missing and the preview would be almost empty on the real list. The plain `export` CLI still defaults to confirmed only.
- **The flagged-first queue cannot be built usefully yet.** It sorts groups by the agent's `flag`, and nothing sets flags until the agent's skill (`docs/SPEC_phase1_distill.md` §7) exists. The skill is a new file under `.claude/skills/`, so propose it first.
