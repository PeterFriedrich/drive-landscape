## 4. Technical Learnings
- **fastembed's default batch (256) pads every batch to its longest text.** In list order that run took 104–123 s and 1.3 GB. `src/embed.py` sorts texts by length and uses `BATCH_SIZE = 32`: 25 s, about 300 MB, vectors identical (cosine 1.0 against the default run). Sorting matters more than the batch size (unsorted batch 32: 71 s; unsorted 8: 50 s). The laptop was under other load (load average 4–7), so the times are rough.
- **The list has few duplicates.** Only 143 of 1,355 items fall in a same-thing group, so collapsing rewordings removes about 80 lines. The distilling has to happen by theme, and **themes are not review state**: they exist only in `proposal.json`, and no op renames, merges or confirms one. The spec (§5) names this as the gap for step 4.
- **245 themes is probably too many** for sections of one list. `--theme-cut` on `propose` is the knob; on this list 0.75 gives 199 themes (largest 63) and 0.80 gives 153 (largest 122).
- **To re-run `propose`** on todo-001, move `work/proposal.json` and `work/log.jsonl` away first; the refusal is deliberate, since a new proposal renumbers the groups under any decisions already logged.
- Embedding cosines of unrelated short texts sit well above zero, which is why the distance measures meaning from the document's median pair. Combined-distance percentiles on the real list: 0.1% = 0.42, 1% = 0.60, 5% = 0.73, median = 0.99.
- Items carry no heading path in the Reminders list, and only 2 of 1,355 are subtasks, so nothing is prepended to the text before comparing.
- `section` (in / out for parts of a scattered document) is not in `src/state.py`; it waits for the Markdown reader.
- **Laptop paths differ from S01's notes:** the repo is at `~/data-projects/drive-landscape`, not `~/drive-landscape`. `.venv`, `core.hooksPath = .githooks` and the private clone were already in place here. System `python3` is 3.11.5; use `.venv/bin/python`.
