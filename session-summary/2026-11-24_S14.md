## 3. Technical Learnings
- **Drive connector limits:** `read_file_content` reads a Doc with its headings; `create_file` makes a Doc from text/markdown; `update_file` changes metadata only and cannot edit Doc text. Docs the owner made in the Drive UI show `canEdit:false`. No OAuth client is needed for this read path. `src/live.py`'s `drive.file` scope cannot open owner-made Docs at all.
- **Headings carry meaning:** each line's heading is kept as `from`. Lines under the heading "Immediate Concern" get `immediate: true` automatically.
- **Artifact `db`:** `claude.use("db")` → `collection("edits").add/onSnapshot`, `doc(id).delete()`. ArtifactData `list` as owner sees owner-only docs; at `as_level: admin` it sees none. `prompt()` doesn't work in artifacts, so move/rename use inline controls. Republish omitting `capabilities` to keep the store rules.
- **JS/Python parity:** a 9-edit sequence (mark, newtheme, move, drop, restore, rename, theme marks) gives identical state in `page.html` and `apply.py`. Restore of an item whose theme emptied recreates the theme under its stored `theme_name` (both sides).
- **Gotchas hit:** `| tail` hid pytest's exit code once and a stale `docs/BRIEF.md` slipped into a commit; chain checks with `&&`. `make_brief.py` needs `--write`. `check_decisions_log.py` refuses a row that partly reopens an older row unless that row is marked in place.
